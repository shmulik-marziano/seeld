# סימן הלוגו החי

הסימן החי הוא גרסה מונפשת של סמל האתר (הטיפה, העלה וחמש הנקודות), כרכיב React בשם `LogoMark`.
הקבצים: `src/components/brand/LogoMark.tsx`, `logo-mark.css`, `logoMarkPaths.ts`.

## מצבים

- `idle` - מנוחה. עם `breathe` הנקודות נושמות לאט.
- `listening` - כמו מנוחה, ועלה שמתנדנד קלות (3.2 שניות).
- `thinking` - הנקודות מתחלפות במקומות במסלול סביב הטיפה. `aria-busy="true"` בזמן החשיבה.
- `speaking` - כמו מנוחה, והנקודות פועמות בעדינות בהפרש של 120 מילי-שניות.

היציאה מ-`thinking` עוברת דרך `useLogoMarkSettle`: הנקודות קופאות במקום וגולשות הביתה תוך 900 מילי-שניות.

## מאפיינים

`state`, `size` (למשל `"48px"`), `breathe`, `onDark`, `instant`, `className`, `label`.
בלי `label` הסימן מוסתר מקוראי מסך. `instant` מיועד לרכיב שנטען ישר במצב חשיבה: בלי מעבר ובלי המתנה.
תנועה מצטמצמת לפי `prefers-reduced-motion` (הנקודות מהבהבות בעדינות במקום להסתובב).

## מתגים

- `VITE_LIVE_MARK=off` - מחזיר את המשגר, הפאנל ומעבר הנקודות הישנים.
- `VITE_CHAT_NUDGE=off` - מכבה את ההצעה העדינה, את במת הצ'אט בדף הבית ואת כרטיס הפנייה בתוך הצ'אט.

שני המתגים דלוקים כברירת מחדל. בבנייה של v2 ההצעה והבמה כבויות בכל מקרה.

## מקור ההדגמה

קובץ ההדגמה המקורי (`Animated_logo_chat_demo.html`) נשמר מחוץ למאגר, בתיקיית הידע של המיתוג.
נתיבי ה-SVG הועתקו ממנו בצורה אוטומטית ולא נערכו ידנית.
