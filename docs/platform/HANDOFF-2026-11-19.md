## 10. מוסכמות עבודה ו"מלכודות" שנלמדו

- הבעלים מאשר בקצרה בעברית ("מאושר"); שפת צו = חוק קשיח; לשאול כשלא בטוחים; לא לבצע בדיקות־יתר שלא נדרשו.
- Ultracode/Workflows מופעלים בסשנים אלה; מגבלת שימוש של Fable עד **2026-11-24** → להריץ סוכני־משנה עם `model: 'opus'`.
- `context-mode` חוסם `curl` → להשתמש ב-Python `urllib` דרך `ctx_execute`. `sleep` משורשר ב-Bash חסום → טיימר ברקע (`run_in_background`).
- Workflow עם `isolation: 'worktree'` נכשל ("not in a git repository") → ליצור worktree ידנית (`git worktree add -b <branch> C:/tmp/wt/<name> origin/main`) ולהצביע עליו.
- נתיבי MSYS בדוקר: `MSYS_NO_PATHCONV=1` ו-`-w //w`.
- Data API ב-Supabase: שמירה ראשונה בדשבורד לא הגיעה ל-PostgREST — **תמיד לאמת** בבקשה עם `Accept-Profile` אחרי שמירה.
- Vercel: לאמת פריסה אחרי כל push (`list_deployments`); תצוגות מקדימות מוגנות SSO (לבדוק דרך כרום מחובר); `/direct-debit` נכשל פעם אחת ב-prerender timeout — flake חד־פעמי.
- הצעות (`ci.proposed.yml`, `config.proposed.toml`, `vercel.proposed.json`) חייבות להיות **זהות** לקבצים החיים — אחרי עריכה: `cp`.
- בנייה מקומית מלאה: `npm run build` (prerender 88/88, check:aeo, size:check); בדיקות: `npx vitest run`; טיפוסים: `npx tsc --noEmit -p tsconfig.json`; lint: `npx eslint <file>`.
- IndexNow אחרי פריסה של עמודים חדשים: `npm run indexnow -- /path1 /path2`.
- מיזוג ענפים: ליצור PR, לחכות ל-`ci-ok`, לאמת בתצוגה מקדימה, `gh pr merge <n> --merge` (**בלי** `--delete-branch`).
- קומיטים מסתיימים בשורות הייחוס של Claude (ראה קומיטים אחרונים כדוגמה).
